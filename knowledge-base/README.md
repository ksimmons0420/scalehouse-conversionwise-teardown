# Landing Page Agent — Psychology & Structure Knowledge Base

The permanent reference the Scale House Landing Page Agent loads on every build. Combines the ConversionWise "Conversion Design" PDP structure (see the repo root `/README.md` teardown + creatives) with Scale House's full persuasion, copy, build, and buyer-psychology stack.

## Load order
1. **[00 — `conversion-design-pdp` Master Blueprint](./00-conversion-design-pdp-blueprint.md)** ← start here. The build spec: 7 pre-build inputs → section blueprint → niche adaptation → QA gates. Every other file is a deep reference this blueprint pulls from.
2. **[01 — Conversion Psychology & CRO](./01-conversion-psychology-cro.md)** — 25+ cognitive biases mapped to on-page elements, friction reduction, CTA/trust/offer/pricing psychology, mobile behavior, measurement (ICE, hypothesis format, false-positive avoidance).
3. **[02 — Persuasion Copywriting](./02-persuasion-copywriting.md)** — Schwartz awareness stages × traffic source, market sophistication, copy frameworks (PAS/AIDA/BAB/4Ps/FAB/PASTOR/SSS), 10 headline formulas, feature→benefit→meaning, VoC mining, objection handling, microcopy, readability.
4. **[03 — Page Structure, Build & Instrumentation](./03-page-structure-build-instrumentation.md)** — canonical section order, mobile-first rules, hero composition, forms (JotForm gotchas), trust placement, CWV targets, accessibility, UTM/funnel attribution, A/B wiring + never-go-dark program.
5. **[04 — Buyer Psychology & Niche-Adaptation Matrix](./04-buyer-psychology-niche-matrix.md)** — awareness/intent by traffic source, message-market match, hero-emotion selection, trust tiers by price/risk, objection maps, and the 7-vertical adaptation matrix.

## The one-line version
Resolve traffic source + vertical → pick one hero emotion → match the headline to awareness stage in the customer's own words → build the CW section structure → neutralize the vertical's top-2 objections above the fold → subtract all friction → pass the CWV + instrumentation gates → ship with a live A/B test.
